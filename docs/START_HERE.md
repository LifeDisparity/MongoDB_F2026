# Start here — Safe Harbor

This branch implements the Safe Harbor handoff. **Do not use the old Living Atlas ticket plan for new work.** Legacy docs/modules remain for inspection; no completion claim transfers automatically.

1. Read [Safe Harbor specification](safe-harbor/SPECIFICATION.md).
2. Find and claim work in the [Safe Harbor ticket board](safe-harbor/TICKETS.md).
3. Follow the [claim and contribution protocol](safe-harbor/CONTRIBUTING.md). Live GitHub ownership is authoritative.
4. Use [v1 contracts](safe-harbor/CONTRACTS.md) and [startup](safe-harbor/STARTUP.md).

**NO UNIT TESTS. NO COMPONENT TESTS. E2E ONLY.**
